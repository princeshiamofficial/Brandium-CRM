# Triage Labels

The canonical triage roles are:

- `needs-triage`: A new issue or request that has not yet been processed.
- `needs-info`: Blocked on missing user information or requirements clarification.
- `ready-for-agent`: Fully specified and ready for AI coding agents to implement.
- `ready-for-human`: Requires manual human action, credentials, or approval.
- `wontfix`: Out of scope or rejected.
